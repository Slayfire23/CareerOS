# Projects and accomplishments

Optional for every career; an empty section must not be treated as a qualification weakness by future matching. Adding an entry requires only a title (100 characters). Description, personal contribution, and results are optional (5000 characters each). Skills: up to 10 newline-separated values of 100 characters. Supporting links: up to 5 absolute HTTP(S) URLs, 2000 characters each; embedded credentials and other protocols are rejected. Links are displayed, never fetched, and open with noopener/noreferrer. No GitHub account, dates, or technology-specific fields required.

A profile-owned ProjectAccomplishment table preserves other profile information. Add derives ownership from verified identity; edit/remove scope by record ID and verified identity. Test the additive migration locally before hosted rollout.

Local verification: 170 unit tests, 18 database tests, TypeScript and lint passed. Restart the app against local test PostgreSQL to load the regenerated client, run build and all 18 browser tests, then review hosted migration before deployment.
