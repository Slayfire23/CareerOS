# Equivalence review — Batch 4: logistics, office, legal, education, HR and sales

**Owner decisions recorded 2026-11-10 (see the end of this packet): ten approved, four held.** The fourteen remaining source-checked groups (Batches 1–3 decided the others; phlebotomy, oil changes, routine vehicle maintenance, conduit, non-conformance and ductwork are held). Forklift operation, reserved earlier for logistics, is included here.

## Method

Each group was simulated on its own, one fresh process per table, with the production `readAnswer` and a Skills/Required request: **current** (Batch 3 table with six approvals; blueprint reading was held afterwards and shares no requirement name or phrase with these groups), **as written** (only this group approved, unchanged) and **candidate** (only this group approved, exact phrases only, no verb–object patterns, related-only entries unchanged, listed requirement names removed). History is the same 1,266 opened answers used for Batch 3, with labels read from each set's own fields (`truly_qualified` / `acceptable_after` for m11_review and m11_remediation). The current table reproduced the implemented Batch 3 readings exactly (0 mismatches). No sealed data, model calls, production writes or baseline rewrites.

Lessons from Batch 3 are built into the candidates: only past-tense phrases (present-tense phrases are exposed to teaching, learning, intention and purpose clauses, see B3-BLUEPRINT), and no phrase that commonly continues as a noun modifier. Probes deliberately include those traps. Three candidates were revised once after the first run; the tables below show the revised candidates only, and the dropped phrase is named in the recommendation.

**S** = Supported (self-reported); **P** = Possible; **I** = Not enough information. Negative probes must not reach S.
