# Equivalence Groups: Owner Review Packet

42 groups, all `source_checked`, none approved. **None can grant Supported until you approve it.** Today a group can only lift an answer to Possible. An approved group can also grant Supported — Self-reported, and treat its names as one question so people aren't asked twice.

## How to review

For each group, mark **Approve**, **Edit**, or **Reject**. Ask of each phrase: if a person's own sentence said this, in a job, would you accept that they did the named work? The shared safety checks still run on every answer, so third-party, negated, hypothetical, and injected text can't count through an approved group.

Things to look for:

- **Patterns are wider than phrases.** A pattern is a listed verb up to seven words before a listed object, in one sentence. Some could fit another trade: "check the truck" for an insurance adjuster, for example.
- **Sources show the occupation, not each phrase.** Each cites an O\*NET 31.0 task from the occupation that does the work. It shows that the occupation does this kind of work. It doesn't prove a phrase is equivalent. I chose the phrases by hand.
- **`discovery`** cites a general legal-documents task, because O\*NET doesn't mention interrogatories or discovery responses.
- **The examples below are generated from the table.** They show how the rule reads, and aren't taken from real people.

To record decisions, return this file marked up or reply with the group names. Approval is then a one-word status change per group, covered by tests.
