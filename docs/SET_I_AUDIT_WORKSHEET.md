# Set I label audit

**Your job:** decide each item yourself, the way you did for Set H. Reply with a list such as `A-01 NEI, A-02 S`, in any order. Say as much or as little as you like about why, and "unsure" is a fine answer.

| Verdict | Short form | Meaning |
|---|---|---|
| Supported | S | Direct evidence of what's asked |
| Possible | P | Plausible, but not direct |
| Not supported | NS | The profile shows it isn't met |
| Not enough information | NEI | Nothing settles it, or it's ambiguous or manipulated |

**How this was built:** 30 of Set I's 276 requirements, picked at random with a fixed seed from each outcome type and spread across subject areas. It's weighted toward disagreements, so it isn't a random sample of the whole set: it checks whether the labels can be trusted where they matter, and can't give a single overall accuracy number.

**It's blind:** the engine's verdict and both AI labels are left out so they can't sway you, and are stored separately in `tests/fixtures/set_i_audit_key.json`. Please don't open that file until you've answered.

**What happens next:** your answers are reported separately as a check on the labels. Set I stays spent: it's not rerun as acceptance, Set I's own labels aren't changed, and no rule is tuned to your answers before Set J freezes unless you decide otherwise. All names and details are invented. Assume today is November 2026.
